\section*{Use of Artificial Intelligence}
\addcontentsline{toc}{section}{Use of Artificial Intelligence}

Artificial-intelligence tools, principally Anthropic's Claude Code, were used
throughout this project as an enhancement to the author's own work and not a
replacement for it. They supported two activities, namely building the code base
behind the platform and reformulating and reviewing the prose of this report.
The author directed the work in every case, read and understood every line of
generated code before committing it, and confirmed and reviewed every design
decision, never adopting a suggestion unchecked. Responsibility for the final
code, the design choices, and the text of this report rests with the author.

The collaboration is recorded so that it can be inspected. Each commit made
together with Claude carries a co-authorship trailer in the project's Git
history, so the tool's involvement in any individual change is traceable. The
plans and design notes that Claude produced during the work are kept in the
repository's \texttt{docs} folder, where they sit alongside the code and
documents they shaped. The repository is available at
\url{https://github.com/vietnhprivat/algo-repo-public}.
